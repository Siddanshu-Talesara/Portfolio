HOW TO ADD YOUR PHOTO
---------------------
1. Open your Portfolio repository on GitHub.
2. Click "Add file" -> "Create new file".
3. Type: assets/README.txt and commit it. This creates the assets folder.
   OR simply create an "assets" folder on your computer.
4. Upload your photo into the assets folder.
5. Rename the photo exactly:
   profile.jpg

Your repository should look like:

Portfolio/
  index.html
  style.css
  script.js
  assets/
    profile.jpg

The HTML already uses:
<img src="assets/profile.jpg">

PHOTO RECOMMENDATION
--------------------
- Use a clear head-and-shoulders photo.
- Portrait orientation works best.
- Suggested crop ratio: 4:5.
- Suggested resolution: around 1000 x 1250 pixels.
- Keep the image under roughly 1-2 MB for faster loading.

HOW TO UPDATE GITHUB PAGES
--------------------------
1. Go to:
   https://github.com/siddanshu-talesara/Portfolio
2. Replace index.html, style.css and script.js with these updated files.
3. Add assets/profile.jpg.
4. Commit the changes to your GitHub Pages branch (usually main).
5. Open:
   https://siddanshu-talesara.github.io/Portfolio/

If GitHub Pages is already enabled, the site will update after the commit is published.
